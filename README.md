# ForgeTorch

ForgeTorch is a real-time-processing orchestrator that optimizes cloud-enabled infrastructure with auto-scaling capabilities.

ForgeTorch is built to be simple and practical, focusing on doing one thing well.

**Why ForgeTorch?**

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/ForgeTorch.git`
2. `cd ForgeTorch`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
